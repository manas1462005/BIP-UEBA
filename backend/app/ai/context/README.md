# Context Intelligence & Reasoning Engine

## Overview
The **Context Intelligence & Reasoning Engine** evaluates raw **Hybrid Anomaly Scores** against 5 dimensions of enterprise context before any security decisions are made:
1. **Trust Reasoning**: Device compliance, IP trust, VPN, MFA verification.
2. **Relationship Reasoning**: Relationship graph distance & project alignment.
3. **Calendar Reasoning**: Schedule drivers (Release Weekends, Maintenance Windows, Holidays).
4. **Access Policy Reasoning**: RBAC, JIT temporary access, Break-glass privileges.
5. **Business Criticality**: Resource sensitivity & system impact.

## Output
The engine produces structured **Context Assessments**, **Context Confidence**, supporting/contradicting evidence, and machine-readable **Reasoning Traces**.
