# End-to-End AI Orchestration & Live Data Pipeline

## Overview
The **Event Processing Pipeline** unifies all AI engines (Behaviour Profiling, Hybrid Anomaly Detection, Context Reasoning, Threat Classification, and Explainability Generation) into one continuous execution flow.

## Event Pipeline Flow
```
Simulated Event
       │
       ▼
Feature Extraction & Baseline Profile Update (Phase 3)
       │
       ▼
Hybrid Anomaly Score Computation (Phase 4)
       │
       ▼
Context Reasoning Assessment (Phase 5)
       │
       ▼
Threat Classification & MITRE Mapping (Phase 6)
       │
       ▼
Explainability & Timeline Report Generation (Phase 7)
       │
       ▼
Database Persistence & WebSocket Broadcast (Phase 8.5)
```
